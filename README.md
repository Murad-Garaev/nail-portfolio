## 🧩 За что отвечает каждый файл

| Файл | Что содержит / отображает |
|------|---------------------------|
| `index.html` | Главная: слайдер работ, блок гарантий, счётчик клиентов, форма записи |

| `script.js` | Загрузка данных из JSON, слайдер, лайтбокс, отправка формы, попап |

## 📝 Как редактировать контент (самое важное)

Все тексты, цены, соцсети, работы и отзывы лежат в папке **`content/`** в виде JSON-файлов.  
Изменить их можно прямо на GitHub:

1. Зайдите в папку `content`  
2. Откройте нужный файл (например, `settings.json`)  
3. Нажмите ✏️ **Edit**  
4. Внесите изменения  
5. Нажмите **Commit changes**

Через 1–2 минуты сайт обновится автоматически.

🖼️ Как добавить фото
Зайдите в папку images

Нажмите Add file → Upload files

Перетащите фото

Укажите путь в JSON:
"image": "images/название_файла.jpg"
