# 💅 Маникюрная студия — сайт-портфолио

Современный, адаптивный сайт для мастера маникюра.  
Контент редактируется через JSON-файлы — без программирования.

🔗 **Сайт:** [https://murad-garaev.github.io/nail-portfolio/](https://murad-garaev.github.io/nail-portfolio/)

---
## 📁 Структура проекта (таблица)

### Корневые файлы

| Файл             | Тип         | Назначение                                                    | Редактируется          |
|------------------|-------------|---------------------------------------------------------------|------------------------|
| `index.html`     | HTML        | Главная страница (слайдер, гарантии, форма)                   | ❌ редко               |
| `about.html`     | HTML        | Страница «Обо мне»                                            | ❌ редко               |
| `portfolio.html` | HTML        | Страница портфолио (галерея + фильтр)                         | ❌ редко               |
| `prices.html`    | HTML        | Страница «Услуги и цены»                                      | ❌ редко               |
| `reviews.html`   | HTML        | Страница отзывов                                              | ❌ редко               |
| `blog.html`      | HTML        | Страница блога                                                | ❌ редко               |
| `contact.html`   | HTML        | Страница контактов (карта, форма)                             | ❌ редко               |
| `style.css`      | CSS         | Все стили (цвета, шрифты, анимации)                           | ❌ редко               |
| `script.js`      | JavaScript  | Логика (загрузка JSON, слайдер, форма, попап)                 | ⚠️ только для Telegram |
| `README.md`      | Markdown    | Документация проекта                                          | ✅ можно               |

### Папка `content/` — всё, что вы редактируете

| Файл             | Формат | Что содержит                                           | Как часто менять |
|------------------|--------|--------------------------------------------------------|------------------|
| `settings.json`  | JSON   | Заголовки, тексты «Обо мне», телефон, email, соцсети   | ✅ часто         |
| `services.json`  | JSON   | Названия услуг, описания, цены                         | ✅ часто         |
| `portfolio.json` | JSON   | Названия работ, описания, пути к фото, категории       | ✅ часто         |
| `reviews.json`   | JSON   | Имена клиентов, тексты отзывов, фото (опционально)     | ✅ часто         |
| `blog.json`      | JSON   | Заголовки статей, даты, текст, фото                    | ✅ часто         |

### Как редактировать разные части сайта

| Что хотите изменить                         | Какой файл открыть          | Что сделать                                          |
|---------------------------------------------|-----------------------------|------------------------------------------------------|
| Заголовок на главной                        | `content/settings.json`     | изменить `heroTitle`                                 |
| Текст под заголовком                        | `content/settings.json`     | изменить `heroText`                                  |
| Короткий текст «Обо мне»                    | `content/settings.json`     | изменить `aboutShort`                                |
| Полный текст «Обо мне»                      | `content/settings.json`     | изменить `aboutFull`                                 |
| Телефон, email                              | `content/settings.json`     | изменить `phone`, `email`                            |
| Ссылки на соцсети                           | `content/settings.json`     | изменить `socials`                                   |
| Услуги и цены                               | `content/services.json`     | добавить/удалить/изменить объекты                    |
| Работы в портфолио                          | `content/portfolio.json`    | добавить/удалить/изменить объекты                    |
| Отзывы                                      | `content/reviews.json`      | добавить/удалить/изменить объекты                    |
| Посты в блоге                               | `content/blog.json`         | добавить/удалить/изменить объекты                    |
| Фото для портфолио                          | `images/`                   | загрузить фото, указать путь в `portfolio.json`      |
| Ссылка на запись (внешняя)                  | `index.html`, `contact.html`| найти `https://ваша-ссылка-на-запись.ru` и заменить  |
| Номер телефона в липкой кнопке              | `index.html`                | найти `href="tel:` и заменить                        |
| Токен Telegram бота                         | `script.js`                 | найти `BOT_TOKEN` и `CHAT_ID`                        |
| Адрес и карта                               | `contact.html`              | найти блок `work-info` и `map-container`             |
| Цифра счётчика клиентов                     | `index.html`                | найти `data-target="150"` и изменить                 |

### Типы файлов и их сложность

| Тип файла                  | Сложность | Кто редактирует | Примечание                            |
|----------------------------|-----------|-----------------|---------------------------------------|
| `.html`                    | ⭐⭐       | разработчик     | лучше не менять без необходимости     |
| `.css`                     | ⭐⭐       | разработчик     | меняется редко (цвета, шрифты)        |
| `.js`                      | ⭐⭐⭐      | разработчик     | только для настройки Telegram         |
| `.json` в `content/`       | ⭐         | **вы**          | редактируете постоянно                |
| `.jpg` / `.png` в `images/`| ⭐         | **вы**          | загружаете новые фото                 |
